# What is PlopUI?

<p className="lede">PlopUI (also written Plop UI or plop-ui) is an open source React component library that looks hand-drawn on purpose: wobbly stickers, washi-tape tags and a hand-lettered marker font. It breaks the visual rulebook, never the accessibility one.</p>

## In one sentence

PlopUI is a free, MIT-licensed set of hand-drawn React UI components, built on native HTML elements, tested with a keyboard and accessible to WCAG AA, made by Lark Sigmuond Babao.

## Who it's for

PlopUI is for products that should feel made by a person, not generated by a template:

- creative tools, sketchbooks and note apps
- learning apps, kids' products and games
- portfolios, side projects and launch pages
- any app where a little warmth helps more than a perfectly neutral grid

It isn't the right pick for dense enterprise dashboards where every pixel has to stay quiet. For those, a neutral kit is a better fit.

## What makes it different

- **Native elements first.** A button is a real `<button>`, a checkbox is a real checkbox, a text field is a real `<input>`. The hand-drawn look is decoration on top, not a replacement for the element.
- **Accessible to WCAG AA.** Every interactive component supports the keyboard and has a test for it. Status never relies on color alone, and every animation calms down under reduced motion.
- **Seeded, not random.** Every tilt, wobble and jitter comes from a seed instead of `Math.random()`, so the server and the browser draw exactly the same crooked line and nothing flickers during hydration.
- **Built for the App Router.** Interactive components ship with `"use client"`, static ones stay Server Components, and the package never imports from `next/*`, so it also runs in any React 19 app.
- **Tokens, not hex.** Colors, type and motion are CSS variables from `@plop-ui/tokens`, with measured contrast.
- **Its own font.** Sketchpop, the marker lettering, ships as `@plop-ui/fonts` under the SIL Open Font License.

## What's in the box

Three packages: `@plop-ui/react` (components, hooks and the buddy cast), `@plop-ui/tokens` (design tokens as CSS variables and a typed object) and `@plop-ui/fonts` (Sketchpop). The components cover actions, inputs, display, feedback and loading. See [every component](/docs/components/button) or try them in the [Playground](/playground).

## How it compares to other hand-drawn kits

Most hand-drawn React libraries draw their shapes at runtime with [Rough.js](https://roughjs.com) or wired-elements. Examples are hand-drawn-ui, Skeci UI, SketchUI and bydefaulthuman. That gives a lovely sketchy look, and each takes its own approach.

PlopUI takes a different route. It ships its own drawn SVG marks, seeds every wobble so server and client match, and starts each component from the native element, with keyboard tests and reduced-motion support built in. The look is closer to stickers, tape and marker on paper than to pencil sketches.

## Not Plop, the code generator

PlopUI has nothing to do with Plop (plopjs.com), the micro-generator for scaffolding files. If you were looking for that, it lives at <a href="https://plopjs.com" rel="nofollow">plopjs.com</a>.

## Questions

**Is PlopUI free?** Yes. The code is MIT-licensed and the Sketchpop font is under the SIL Open Font License, so both are free for personal and commercial projects.

**Do I need Next.js?** No. PlopUI works in any React 19 app. Next.js gets extra care: see [Using with Next.js](/docs/nextjs).

**Is it ready for production?** The components are tested, but PlopUI is still before 1.0, so some names may change. Pin your version and read the [changelog](/changelog) when you upgrade.

**How do I start?** Follow [Installation](/docs/getting-started). It takes two packages, two CSS imports and one provider.

**Where's the code?** On [GitHub](https://github.com/Snorlark/plop-ui). Issues and pull requests are welcome.
