## Server Component

Without `onRemove`, `Tag` renders as a Server Component and ships no JavaScript. With `onRemove` it renders a small client part for the remove button and the peel-off.

## Accessibility

- The status is always written in the label; the color only repeats it.
- The remove button is named "Remove &lt;label&gt;" (or `removeLabel`).
- After a tag is removed, focus moves to the next tag's remove button, or the previous one if it was the last.
- Under reduced motion the tag disappears at once instead of peeling off.
