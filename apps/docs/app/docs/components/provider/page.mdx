# PlopProvider

<p className="lede">Sets the surface, theme and feedback settings for everything inside it, and renders the SVG filters the hand-drawn outlines use.</p>

```tsx
<PlopProvider surface="poster" theme="system" haptics sound={false} reducedMotion="system">
  {children}
</PlopProvider>
```

## Notes

- `theme="system"` follows `prefers-color-scheme`; `reducedMotion="system"` follows `prefers-reduced-motion`.
- `sound` is off by default. Only turn it on after a person asks for it.
- Components work without a provider, but outlines won't wobble or boil (the filters live in the provider).
