# Smart CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CI that classifies each change and runs only what matters, once, in parallel, behind a single required `ci` gate, plus a guide.

**Architecture:** A pure, unit-tested classifier (`scripts/ci-changes.mjs`) decides what to run from the changed files; a thin CLI wrapper feeds it git data and writes GitHub outputs. `ci.yml` becomes `changes` → (`check` ∥ `build-site` → `e2e` matrix) → `ci` gate. `release.yml` drops its test run and dispatches CI on the bot's version PR.

**Tech Stack:** GitHub Actions, Node 22 (`node:test`), pnpm 11, Turborepo, Next.js 15, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-27-smart-ci-design.md`

## Global Constraints

- Playwright projects, exactly: `desktop`, `phone`, `firefox`, `safari`, `iphone`. Full = all 5; light = `desktop`, `phone`; after-merge on `main` = `desktop`.
- Browser per project: `desktop`, `phone` → `chromium`; `firefox` → `firefox`; `safari`, `iphone` → `webkit`.
- The required gate job is named exactly `ci`.
- When in doubt (unmatched file, unparsable data, empty diff, unknown event), classify as full.
- Weekly run: `schedule` cron `0 3 * * 1` (Mondays 03:00 UTC), everything.
- No new paid services; third-party actions pinned to a full commit SHA; prefer `actions/*` and shell.
- Keep the existing commands (`pnpm build`, `lint`, `typecheck`, `test`, `size`) and the Playwright suite unchanged.
- Commits: conventional, no Claude attribution, Lark opens the PRs.

## Review Focus

- A renamed or deleted file is classified by both its old and new paths (a page deleted from `apps/docs` is at least light, a moved component is full).
- An empty diff (e.g. a PR whose commits cancel out) runs full, never skips everything.
- File names with spaces or non-ASCII characters are read correctly (`git diff -z`).
- A version PR that adds a new package or changes a non-version `package.json` field is not "version-only".
- The gate fails when a needed job is `cancelled`, not just `failure`.

Each of these has a test in Task 1 (classifier) or a check in Task 4 (live run).

### Task 1: The classifier

**Files:**
- Create: `scripts/ci-changes.mjs`
- Create: `scripts/ci-changes.test.mjs`
- Modify: `package.json` (root): add `"test:ci": "node --test scripts/"`

**Interfaces:**
- Produces, exported from `scripts/ci-changes.mjs`:
  - `classify({ event, branch, files, demoMdx, versionOnly })` → `{ check, buildApps, site, e2e, projects }`
    - `event`: `"pull_request" | "push" | "schedule" | "workflow_dispatch"`; `branch`: head branch name.
    - `files`: `Array<{ path: string, oldPath?: string, status: "A"|"M"|"D"|"R" }>`.
    - `demoMdx`: `Set<string>` of `.mdx` paths whose changed lines contain `<[A-Z]` or `import `.
    - `versionOnly`: `(path) => boolean`, true for a `packages/*/package.json` identical to the base's after parsing, ignoring `version` and `@plop-ui/*` dependency versions.
    - `check`: `"skip" | "changeset" | "full"`; `buildApps`: boolean (build Storybook and the dispatch demo); `site`: boolean (run `build-site`); `e2e`: `"none" | "main" | "light" | "full"`; `projects`: string[] per Global Constraints.
  - `PROJECTS = { full: [...5], light: ["desktop","phone"], main: ["desktop"], none: [] }`, `BROWSER = { desktop:"chromium", phone:"chromium", firefox:"firefox", safari:"webkit", iphone:"webkit" }`.
  - CLI (`node scripts/ci-changes.mjs --base <ref>`): builds the inputs from `git diff -z --name-status -M <base>...HEAD`, `git diff -U0 <base>...HEAD -- '*.mdx'`, and `git show <base>:<path>`, prints the result, and appends `check`, `build_apps`, `site`, `e2e`, `projects` (JSON) to `$GITHUB_OUTPUT` when set. Reads `GITHUB_EVENT_NAME` and `GITHUB_HEAD_REF || GITHUB_REF_NAME`.

- [ ] **Step 1: Write the failing tests** in `scripts/ci-changes.test.mjs` with `node:test` and `node:assert/strict`, one `test()` per row and rule:

```js
const pr = (files, extra = {}) => classify({ event: "pull_request", branch: "feat/x", files: files.map((p) => (typeof p === "string" ? { path: p, status: "M" } : p)), demoMdx: new Set(), versionOnly: () => false, ...extra });

test("library change: full checks, Storybook/demo builds, all 5 browsers", () => {
  assert.deepEqual(pr(["packages/react/src/Select/Select.tsx"]), { check: "full", buildApps: true, site: true, e2e: "full", projects: ["desktop", "phone", "firefox", "safari", "iphone"] });
});
test("site code change: all 5", () => assert.equal(pr(["apps/docs/app/_home/StickerPack.tsx"]).e2e, "full"));
test("site css change: all 5", () => assert.equal(pr(["apps/docs/app/site.css"]).e2e, "full"));
test("mdx text-only: light, no app builds", () => assert.deepEqual(pr(["apps/docs/app/docs/nextjs/page.mdx"]), { check: "full", buildApps: false, site: true, e2e: "light", projects: ["desktop", "phone"] }));
test("mdx with a demo line: full", () => assert.equal(pr(["apps/docs/app/docs/hooks/page.mdx"], { demoMdx: new Set(["apps/docs/app/docs/hooks/page.mdx"]) }).e2e, "full"));
test("public asset: light", () => assert.equal(pr(["apps/docs/public/readme/fonts.png"]).e2e, "light"));
test("tooling change: full", () => { for (const f of [".github/workflows/ci.yml", "pnpm-lock.yaml", "turbo.json", "package.json", "apps/docs/playwright.config.ts", "apps/docs/e2e/pack.spec.ts", "scripts/publish.mjs"]) assert.equal(pr([f]).e2e, "full", f); });
test("storybook only: full checks with app builds, no browsers", () => assert.deepEqual(pr(["apps/storybook/stories/Tag.stories.tsx"]), { check: "full", buildApps: true, site: false, e2e: "none", projects: [] }));
test("changeset or changelog: site build only", () => { for (const f of [".changeset/brave-cats.md", "packages/react/CHANGELOG.md"]) assert.deepEqual(pr([f]), { check: "skip", buildApps: false, site: true, e2e: "none", projects: [] }, f); });
test("notes only: changeset status, nothing else", () => assert.deepEqual(pr(["TASKS.md", "docs/ci-cd.md", "README.md", "LICENSE"]), { check: "changeset", buildApps: false, site: false, e2e: "none", projects: [] }));
test("strongest rule wins", () => assert.equal(pr(["TASKS.md", "apps/docs/app/docs/nextjs/page.mdx", "packages/tokens/src/tokens.ts"]).e2e, "full"));
test("unmatched file defaults to full", () => assert.equal(pr(["something/new.txt"]).e2e, "full"));
test("empty diff runs full", () => assert.equal(pr([]).e2e, "full"));
test("renamed file counts its old path", () => assert.equal(pr([{ path: "docs/old-component.md", oldPath: "packages/react/src/Old.tsx", status: "R" }]).e2e, "full"));
test("deleted docs page is at least light", () => assert.notEqual(pr([{ path: "apps/docs/app/docs/hooks/page.mdx", status: "D" }]).e2e, "none"));
test("path with spaces is matched", () => assert.equal(pr(["apps/docs/public/a b.png"]).e2e, "light"));
test("version PR, versions only: site build only", () => {
  const r = classify({ event: "workflow_dispatch", branch: "changeset-release/main", files: [{ path: "packages/react/package.json", status: "M" }, { path: "packages/react/CHANGELOG.md", status: "M" }, { path: ".changeset/brave-cats.md", status: "D" }], demoMdx: new Set(), versionOnly: () => true });
  assert.deepEqual(r, { check: "skip", buildApps: false, site: true, e2e: "none", projects: [] });
});
test("version PR with a real package.json change: full", () => assert.equal(classify({ event: "workflow_dispatch", branch: "changeset-release/main", files: [{ path: "packages/react/package.json", status: "M" }], demoMdx: new Set(), versionOnly: () => false }).e2e, "full"));
test("version PR adding a package: full", () => assert.equal(classify({ event: "workflow_dispatch", branch: "changeset-release/main", files: [{ path: "packages/icons/package.json", status: "A" }], demoMdx: new Set(), versionOnly: () => false }).e2e, "full"));
test("push to main: full checks, desktop only", () => assert.deepEqual(classify({ event: "push", branch: "main", files: [], demoMdx: new Set(), versionOnly: () => false }), { check: "full", buildApps: true, site: true, e2e: "main", projects: ["desktop"] }));
test("schedule and manual runs: everything", () => { for (const event of ["schedule", "workflow_dispatch"]) assert.equal(classify({ event, branch: "main", files: [], demoMdx: new Set(), versionOnly: () => false }).e2e, "full"); });
```

Also a test for `versionOnly`'s helper, exported as `samePackageJson(baseText, headText)`: true when only `version` and `@plop-ui/*` versions differ or `keywords` is reflowed; false for a changed `description`, a new dependency, or unparsable JSON.

### Task 2: The new CI workflow

**Files:**
- Modify (rewrite): `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: Task 1's CLI outputs `check`, `build_apps`, `site`, `e2e`, `projects`.
- Produces: a job named `ci` (the required check); artifact `site-build` containing `apps/docs/.next-e2e` and `packages/*/dist`.

- [ ] **Step 1: Write the workflow** with these pieces (exact YAML left to the implementer):
  - `on`: `pull_request`, `push: branches: [main]`, `schedule: - cron: "0 3 * * 1"`, `workflow_dispatch`.
  - `concurrency`: group `ci-${{ github.event.pull_request.number || github.ref }}`, `cancel-in-progress: ${{ github.event_name == 'pull_request' }}`.
  - `changes`: checkout with `fetch-depth: 0`; base = `origin/${{ github.base_ref }}` for PRs, `origin/main` for `workflow_dispatch` on a non-main branch, `HEAD~1` for pushes; run the CLI.
  - `check` (if `check != 'skip'`): install, `pnpm test:ci`; when `check == 'changeset'`, only `pnpm changeset status`; otherwise `pnpm turbo run build --filter=./packages/*` (plus `--filter=@plop-ui/storybook --filter=@plop-ui/dispatch-demo` when `build_apps`, plus `--filter=@plop-ui/docs` when `site` is false), then `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm size`.
  - `build-site` (if `site == 'true'`): install, build packages, `NEXT_DIST_DIR=.next-e2e pnpm --filter @plop-ui/docs exec next build`, upload `site-build`.
  - `e2e` (needs `changes`, `build-site`; if `e2e != 'none'`): `strategy.matrix.project: ${{ fromJSON(needs.changes.outputs.projects) }}`, `fail-fast: false`; install, download `site-build`, cache `~/.cache/ms-playwright` keyed `pw-${{ runner.os }}-1.64.1-<browser>`, `playwright install --with-deps <browser>` (or `install-deps <browser>` on a cache hit), then `pnpm --filter @plop-ui/docs exec playwright test --project=${{ matrix.project }}` with `CI=1` and `NEXT_DIST_DIR=.next-e2e`.
  - `ci` (needs all of the above, `if: always()`): fail when any `needs.*.result` is `failure` or `cancelled`; otherwise pass.

- [ ] **Step 2: Validate the YAML locally**

Run: `npx --yes @action-validator/cli .github/workflows/ci.yml` (or `python3 -c "import yaml,sys; yaml.safe_load(open(sys.argv[1]))" .github/workflows/ci.yml` if that package isn't available) · Expected: no errors.

- [ ] **Step 3: Check the Playwright webServer works on a prebuilt site**

Run: `cd apps/docs && NEXT_DIST_DIR=.next-e2e npx next build && CI=1 NEXT_DIST_DIR=.next-e2e npx playwright test --project=desktop` · Expected: all `desktop` tests pass without a second build. (The `webServer` already runs `next start` with `NEXT_DIST_DIR=.next-e2e`; no config change expected.)

- [ ] **Step 4: Commit**

```bash
git add .github/workflows/ci.yml
git commit -m "ci: run only what a change needs, in parallel, behind one ci gate"
```
