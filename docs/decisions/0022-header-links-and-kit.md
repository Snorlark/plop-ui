# 0022: Header sections are links; /kit is gone

- Components, Guides and Playground in the header now go somewhere when pressed (the Button docs, /docs/getting-started, /playground). A small caret beside each opens its mega menu, so keyboard and touch users can still reach the menu without hover. Community has no page of its own and stays a menu button.
- "You are here" and "you're pointing here" look different: hover (or an open menu) draws the mustard highlighter, which pulls back the way it came on leave; the section you're in gets a hand-drawn tomato underline. A menu unrolls down from the bar and rolls back up when it closes.
- /kit is removed. It was the v0.6 prototype rebuilt as one long page, with its own logo, sidebar and surface switcher, and it never matched the rest of the site. Every component already has its own docs page. /kit now redirects to the Button docs, and its cookies (plop-surface, plop-theme) are no longer used.
- The 404 page has no site header: it's one full-screen scene whose buttons lead home, to the components or back.
