# 0014 — Search everywhere, and a home page that argues before it shows how

**Decision.** Every page's header has a search button that opens the kit's `CommandPalette` (⌘K / Ctrl K, or `/`): all components and docs pages, plus quick actions (browse components, playground, paper/mat, copy install, GitHub). The header CTA is "Browse components" (`/kit`).

**Home order.** Hero → letter → **Why PlopUI** (six sticker cards that slap down as they scroll in, each with its character) → the pack → all components → **How a piece is made** (the paper stack) → surfaces → **Plop Pass CTA** → footer. "Made for the people on the line" was removed. The Pass card moved from the footer to the CTA; stamping (visits, GitHub clicks) and the coupon still run on every page from an invisible tracker in the footer.
