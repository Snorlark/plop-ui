# 0013 — Feedback matches intent: confetti for done, a poof for gone

**Decision.** Celebration is for things that went right. `tomato` stickers (cancel, delete, destructive) shake their head and puff a little dust that sinks, never confetti; every other variant keeps the ink burst. `burst="confetti" | "poof"` overrides it. The same rule already holds for characters: Confetti only appears for `congrats`, Bix for errors.

**Also.** The default sticker shadow is now `soft`, a flat offset in the shadow token: quieter and closer to how the site is drawn. The crayon `stripes` are kept as an option. `SearchField` brings the same tactile feel to search.
