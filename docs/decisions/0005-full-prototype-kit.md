# 0005 — Ship the whole prototype kit, not only the v0.1 six

**Decision.** Beyond the PRD's v0.1 list, the library ports every component from the v0.6 prototype: Tooltip, TextField/TextArea, RadioGroup, Avatar, Cards, Tabs, Progress, Callout, Toast, Count/StatusDot, Sheet, Heading, Lettering, and the ink burst.

**Why.** The prototype is the design reference and the author asked for the kit as designed. The docs home page is the prototype rebuilt from the library, so any drift from the design is visible.
