# Security policy

## Supported versions

PlopUI is before 1.0, so only the latest minor release of each package gets fixes:

| Package | Supported |
| --- | --- |
| `@plop-ui/react` | latest 0.x minor |
| `@plop-ui/tokens` | latest 0.x minor |
| `@plop-ui/fonts` | latest 0.x minor |

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe what you found, the affected package and version, and how to reproduce it.

You'll get a first answer within 7 days. Once a fix is released, the advisory is published and you're credited, unless you'd rather not be.

## Scope

In scope: the published packages (`@plop-ui/react`, `@plop-ui/tokens`, `@plop-ui/fonts`), the docs site at plopui.com, and this repository's CI and release workflows.

Out of scope: problems in third-party dependencies that are already reported upstream, and anything that needs a compromised maintainer account.
