Add Pagination with small sticker controls, native links or buttons, current-page semantics, Previous/Next bounds, and ellipses for long page ranges. The changelog now paginates release groups with shareable page and package URLs, retaining navigation to older release anchors. Pagination also has a `compact` variant ("2 of 17" with `formatCount`), `showEnds` for First/Last controls, and a `loading` state that puts a spinner in the current page.
